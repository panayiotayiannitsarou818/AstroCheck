# AstroCheck Pro v14 (Streamlit)

Εφαρμογή ελέγχου Astrodienst Data Sheet και δημιουργίας πλήρους εντολής/Word με οδηγίες v5.3, καθαρό οδηγό ύφους και χωριστή προαιρετική υπηρεσία επαγγελματικού προσανατολισμού.

## Εκτέλεση

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

## Ροή

1. Ανέβασμα μόνο του νέου Astrodienst PDF. Οι οδηγίες v5.3 και ο καθαρός οδηγός ύφους φορτώνονται αυτόματα.
   Μετά την επιτυχημένη ανάγνωση η εφαρμογή ανοίγει αυτόματα την καρτέλα «2 · Έλεγχος». Αν υπάρχει ήδη ελεγμένος χάρτης στη συνεδρία, εμφανίζεται μεγάλο κουμπί «Συνέχεια στον Έλεγχο» χωρίς να απαιτείται νέο ανέβασμα.
2. Ανάγνωση πλανητών, ακμών, Οίκων, ανάδρομης κίνησης και πίνακα όψεων.
3. Υποχρεωτική οπτική επιβεβαίωση τετραγώνων/αντιθέσεων.
4. Συμπλήρωση προσωπικού πλαισίου και γλώσσας.
5. Λήψη master prompt ή προαιρετική αυτόματη συγγραφή με προσωπικό OpenAI API key.
6. Λήψη ελεγμένου τεχνικού Word.
7. Ανέβασμα της ανθρώπινης αναδιατύπωσης και δεύτερος μηχανικός έλεγχος πριν από την τελική λήψη.
   Οι καρτέλες 4, 5, 6 και 7 εμφανίζουν έτοιμο μήνυμα για επικόλληση στο ChatGPT/Claude. Η καρτέλα 6 παρέχει επίσης τη Δεσμευτική Εντολή Τελικής Αναδιατύπωσης για λήψη.
8. Προαιρετικά, επιλογή στην καρτέλα 7 μεταξύ παιδιού/εφήβου και ενήλικα, χωρίς συλλογή πρόσθετων ψυχολογικών, σχολικών, επαγγελματικών ή οικονομικών δεδομένων. Για παιδί/έφηβο είναι υποχρεωτική η απάντηση «Ναι/Όχι» στην ερώτηση «Φοιτά στο κυπριακό εκπαιδευτικό σύστημα;». Με «Ναι» ενεργοποιείται η ξεχωριστή ενότητα για τις ΟΜΠ πριν από την Τελική Σύνθεση και κάθε επαγγελματικός τομέας περιλαμβάνει χωριστά «Ενδεικτικά επαγγέλματα» και «Ενδεικτικές πανεπιστημιακές σπουδές/Τμήματα»· οι επίσημες πηγές καταγράφονται μόνο στο εσωτερικό τεχνικό δελτίο. Με «Όχι» παραλείπεται το κυπριακό εκπαιδευτικό πλαίσιο και δεν υποτίθεται άλλο σύστημα. Επιλέγεται επίσης «Απλή και πρακτική» ή «Αναλυτική με αστρολογική τεκμηρίωση» παρουσίαση. Η κοινή δεσμευτική εντολή περνά στο Word τον τύπο υπηρεσίας, τον τρόπο παρουσίασης και την καθαρή τεχνική πηγή του χάρτη.

9. Στην αναλυτική παρουσίαση επιστρέφεται ένα Word με τεχνικό παράρτημα. Στην απλή παρουσίαση επιστρέφονται δύο Word: το καθαρό παραδοτέο πελάτη και το εσωτερικό τεχνικό δελτίο. Για ενήλικα, η απλή παρουσίαση χρησιμοποιεί καθημερινή γλώσσα και κρατά μόνο σύντομο προφίλ, 4–6 ταλέντα, 4–5 επαγγελματικούς τομείς και τελική σύνθεση. Δεν περιλαμβάνει εργασιακό περιβάλλον, επόμενα βήματα ή σχέδιο 8–12 εβδομάδων. Ο validator ελέγχει αυτή τη μικρότερη δομή χωρίς να απαιτεί τις ενότητες της αναλυτικής έκδοσης.

10. Το αρχείο `Protypo_Syntomis_Ekdosis_Enilikou.docx` είναι ανώνυμο πρότυπο δομής και ύφους. Όταν επιλεγούν «Ενήλικας» και «Απλή και πρακτική», το πρόγραμμα το ενσωματώνει αυτόματα στο Word της εντολής. Δεν χρειάζεται χωριστό ανέβασμα του παραδείγματος του πελάτη.

11. Το αρχείο `Protypo_Syntomis_Ekdosis_Paidiou_Efivou.docx` λειτουργεί αντίστοιχα όταν επιλεγούν «Παιδί/έφηβος» και «Απλή και πρακτική». Η σύντομη ενότητα για το κυπριακό εκπαιδευτικό σύστημα εμφανίζεται μόνο όταν έχει απαντηθεί «Ναι» στη σχετική ερώτηση.

Ο επαγγελματικός προσανατολισμός είναι χωριστή, προαιρετική υπηρεσία. Η κοινή εντολή διατηρεί την ίδια βασική δομή και προσαρμόζει αυτόματα τίτλο, δραστηριότητες, σχέδιο 8–12 εβδομάδων και αποδέκτη οδηγιών ανάλογα με την επιλογή παιδιού/εφήβου ή ενηλίκου. Δεν προστίθεται αυτόματα στη βασική ανάλυση 12 Οίκων.

## Development / Tests

Το test suite (`tests/`, `pytest.ini`) δεν χρειάζεται καθόλου για να τρέξει η εφαρμογή στο Streamlit — καλύπτει τον `validator.py` (και τα δύο στάδια ελέγχου: βασική ανάλυση + τελική αναδιατύπωση) και τη διαχείριση session state (`case_state.py`), με συνθετικά δεδομένα χάρτη. Δεν καλύπτει ακόμη τον `parser.py` (ανάγνωση πραγματικού Astrodienst PDF) — βλ. σημείωση παρακάτω.

Το `pytest` δεν βρίσκεται στο `requirements.txt` (αυτό διαβάζεται από το Streamlit Cloud για το ίδιο το runtime της εφαρμογής και δεν χρειάζεται εκεί), αλλά σε ξεχωριστό `requirements-dev.txt`:

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

Για να τρέξεις την ίδια την εφαρμογή μετά:

```bash
.venv/bin/streamlit run app.py
```

**Γνωστό κενό:** δεν υπάρχουν ακόμη tests με πραγματικά Astrodienst PDF fixtures — ο `parser.py` βασίζεται σε συγκεκριμένες συντεταγμένες pixel πάνω στη σελίδα, και μια αλλαγή στη διάταξη/γραμματοσειρά του Astrodienst export θα τον έσπαγε σιωπηλά χωρίς να το πιάσει κανένα υπάρχον test. Επόμενο βήμα: 2–3 πραγματικά (ανωνυμοποιημένα) PDF ως fixtures.

## Σημαντικό

Η εφαρμογή δεν αντιμετωπίζει την αστρολογία ως επιστημονική ή ψυχολογική διάγνωση. Η Θεωρία των Μοιρών χρησιμοποιείται μόνο συμπληρωματικά. Η τελική ανάλυση πρέπει να περνά ανθρώπινο μαθηματικό, γλωσσικό και οπτικό έλεγχο.

Το ChatGPT ή το Claude πραγματοποιεί μόνο αυτοέλεγχο. Ο πραγματικός validator εκτελείται αποκλειστικά μέσα στην εφαρμογή, μετά την επιστροφή και τη μεταφόρτωση του παραγόμενου Word.
