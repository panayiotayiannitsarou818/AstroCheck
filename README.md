# AstroCheck Pro — τέσσερα βήματα

1. **Αρχεία:** Ανέβασε το Astrodienst Data Sheet PDF και πάτησε «Ανάγνωση και έλεγχος PDF». Ο έλεγχος γίνεται από την εφαρμογή, χωρίς χειροκίνητη επιβεβαίωση.
2. **Δημιουργία:** Επίλεξε αυτόματη δημιουργία με δικό σου OpenAI API key ή στείλε στο ChatGPT/Claude το «Δελτίο ελέγχου και πλήρους εντολής» που διατίθεται στην καρτέλα 3. Ανέβασε εδώ το Word της πρώτης ανάλυσης και πάτησε «Έλεγχος ανάλυσης».
3. **Τεχνικό Word:** Αν ο έλεγχος περάσει, κατέβασε την ελεγμένη πλήρη ανάλυση. Αν αποτύχει, διόρθωσε το Word και ανέβασέ το ξανά στην καρτέλα 2.
4. **Τελική αναδιατύπωση:** Κατέβασε τη Δεσμευτική Εντολή Τελικής Αναδιατύπωσης. Στείλε αυτήν και την ελεγμένη ανάλυση στο ChatGPT/Claude, ανέβασε εδώ το νέο Word, πάτησε «Έλεγχος τελικού εντύπου» και κατέβασέ το αν περάσει.

Δεν υπάρχουν πεδία προσωπικού πλαισίου. Χρησιμοποιείται μόνο το όνομα που διαβάζεται από το PDF. Η επιλογή γλώσσας παραμένει στη δημιουργία. Η ξεχωριστή καρτέλα επαγγελματικού προσανατολισμού αφαιρέθηκε από αυτήν τη διεπαφή. Οι έλεγχοι πληρότητας και τελικής αναδιατύπωσης παραμένουν ενεργοί.

## Εκτέλεση

```bash
pip install -r requirements.txt
streamlit run app.py
```
